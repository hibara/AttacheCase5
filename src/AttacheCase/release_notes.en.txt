[new]
Initial release
Encrypt files and folders with a password (AES-256-GCM and Argon2id)
Post-PPAP: send encrypted files without sharing a password (hybrid RSA-4096 and ML-KEM-768)
Creating and opening password-protected ZIP files are now supported
Opening files (.atc format) created in AttacheCase 4 is supported. However, the reverse is not possible. AC5 → AC4 ❌
Command-line arguments in a format nearly identical to that of the Windows version is now supported
