# アタッシェケース macOS 版の変更点（日本語）
#
# appcast_generate.sh が読み、マニフェストに埋め込む。更新の確認画面に出る。
#
# 書き方
#   [new]          新機能
#   [improvements] 改善
#   [fixes]        修正
#
# 見出しは上の 3 つのいずれか。表示する語（「新機能」など）はアプリ側が持つので、
# ここには書かない。日本語版と英語版で見出しがずれないようにするため。
#
# 行頭が # の行と空行は無視される。1 行が 1 項目。
# リリースのたびに中身を書き換えること（前回のものが残っていると、
# 変わっていない項目を「新しい変更点」として配ってしまう）。

[new]
初公開
パスワードでファイルとフォルダーを暗号化します（AES-256-GCM と Argon2id）
Post-PPAP に対応しました。パスワードを相手に伝えずに送れます（RSA-4096 と ML-KEM-768 のハイブリッド）
パスワード付き ZIP の作成と展開ができるようになりました
アタッシェケース4 で作ったファイル（.atc形式）も開けます。ただしその逆はできません。AC5→AC4❌
Windows 版と、ほぼ同じ書式のコマンドライン引数に対応しました
